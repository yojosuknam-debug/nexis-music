# 함께 부르는 찬송 — 저작권 만료 후보 (직접 피아노 반주용)

> 기준: **선율(작곡자)과 원가사(작사자) 모두 사후 70년이 지난 곡**(한국 기준, 2026년이면 1955년 이전 사망). 근거 조사: [research/2026-10-24_예배-찬송가-저작권.md](research/2026-10-24_예배-찬송가-저작권.md)
> 새찬송가 장 번호는 찾기 편하라고 적은 **참고용**(판본마다 다를 수 있음). 법률 자문 아님.

## ⚠️ 반주는 자유, 한국어 가사는 확인이 필요

| 층 | 이 목록의 곡 | 할 일 |
|---|---|---|
| 선율 | ✅ 저작권 만료 — 직접 피아노로 치면 자유롭게 사용 | 반주는 **악보를 보고 직접 연주**(남의 현대 편곡 음원·편곡 악보를 그대로 따라 치지 않기) |
| 영어 원가사 | ✅ 만료 — 영어 예배 자막에 그대로 사용 | — |
| **한국어 가사** | ❓ 새찬송가·통일찬송가의 한국어 가사는 **한국찬송가공회가 권리를 주장**(편집·번역·개정) | 아래 셋 중 하나: ①공회에 이 곡들의 '관리비율'·허락 문의(곡당 6만 원 × 관리비율, 만료곡은 비율이 낮을 수 있음) ②한국어 가사 없이 **반주만**(묵상 찬송) ③본인이 원가사를 **새로 번역·개사** |

**추천:** 한국어 예배의 '함께 부르기'는 ①로 허락을 받거나, 그 전까지는 ②반주 + "마음으로 함께 불러요" 자막으로 시작. 영어 예배는 바로 가능.

## 녹음해서 보내 주실 것 (곡마다)

1. **피아노 반주 녹음**: 원곡 그대로 1~4절(곡 길이 2~4분), 전주 4~8마디, 끝은 자연스럽게. 휴대폰 녹음도 가능(조용한 방, 피아노에서 1~2m).
2. **절 시작 시간**(예: `1절 0:12 / 2절 0:58 …`) — 가사 자막을 맞추는 데 씀. 모르면 비워 두면 녹음을 듣고 맞춥니다.
3. 쓰는 **악보 출처**(예: Hymnary.org 공개 악보, 옛 찬송가 악보) — 대장에 근거로 남김.
4. 가능하면 같은 곡을 **템포 조금 느린 판**으로 한 번 더 → 기도회 배경 음악으로도 씀.
