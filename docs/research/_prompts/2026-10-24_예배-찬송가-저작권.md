# 역할
당신은 한국 저작권법·음악 저작권 실무의 시니어 리서처이자, 교회 온라인 예배(유튜브 생중계) 운영 자문가입니다.

# 배경 (내가 만드는 것)
- 프로젝트: 매일 자동 제작하는 '말씀 묵상 예배' 유튜브 실시간 방송(한국어 06:00, 영어 11:00, 약 17분)과 저장 영상. 개인이 운영하는 작은 사역 채널이며 수익화 가능성 있음
- 구성: 예배의 부름 → 찬양 1 → 기도 → 성경 봉독 → 말씀 → 결단 기도 → 응답 찬양 2 → 주기도문 → 축복의 말씀. 낭독은 운영자 본인 목소리 복제 TTS, 화면은 교회 프로젝터식 자막
- 현재 상태: 찬양 자리에 운영자가 AI 음악 도구(Suno)로 만든 자작곡을 쓰고 있으나, "실제 예배 중계처럼 찬송가"로 바꾸려 함
- 검토 중인 방식: ①보컬 있는 찬송 ②반주 + 가사 자막만 ③1곡은 보컬, 2곡은 반주만. 반주는 직접 연주 녹음 또는 새로 만든 반주(무료 피아노·오르간 음원, Suno 등 AI 생성)
- 이미 아는 것(다시 설명 불필요): 저작권은 녹음(음원)·곡(선율)·가사(번역 가사 포함)로 나뉜다는 것, 한국 저작재산권 보호기간이 저작자 사후 70년이라는 일반 원칙. 성경 본문은 개역한글을 화면에 쓰고 있음

# 조사 목적
찬송가를 넣는 방식(보컬/반주+자막/혼합)과 곡 선정 기준·허락 절차를 정해, 유튜브에서 저작권 분쟁(Content ID·수익 귀속·삭제) 없이 매일 방송할 수 있는 운영 규칙을 만든다.

# 핵심 질문
1. 새찬송가(645장)의 가사·한국어 번역 가사·편곡·악보의 저작권 귀속과 관리 주체(한국찬송가공회 등), 유튜브 생중계·저장 영상 사용 허락 절차·비용·기간을 현재 시점 기준으로, 변경 이력·분쟁 사례 포함해 정리. 21세기찬송가·통일찬송가와 차이.
2. 저작권이 끝난 찬송가를 가려내는 실무 방법: 선율(작곡자 사망 연도), 원가사, 한국어 옛 번역 가사(번역자·출판 연도), 편곡의 별도 저작권. 확인에 쓸 수 있는 공개 데이터베이스(hymnary.org, 한국 공개저작물 포털 등)와 한국어로 쓸 수 있는 공개저작물 찬송 가사가 실제로 있는지.
3. 방식별 위험 비교(표): 직접 연주 녹음 / 무료 음원으로 만든 반주 / Suno 등 AI로 만든 찬송가 반주·보컬(AI가 기존 찬송 선율을 재현할 때) / 가사 자막 표시 — 저작권·Content ID·수익 귀속·플랫폼 약관 기준.
4. 한국음악저작권협회(KOMCA)와 유튜브의 포괄 이용 계약이 개인 채널의 찬양 연주·가사 사용을 어디까지 덮는지, 수익화 채널과 비수익 채널의 차이, Content ID 소유권 주장이 들어왔을 때 대응.
5. CCLI(Streaming License 포함)·OneLicense 등 교회 예배 라이선스가 한국에서 적용되는지, 한국 교회 생중계의 실제 관행, 비용.
6. 영어 예배용: 미국 기준 공개저작물 찬송가(예: Amazing Grace, Holy Holy Holy, It Is Well with My Soul) 선정 기준, 현대 편곡·현대 가사 개정판의 함정, 공개저작물 악보·MIDI 출처.
7. 성경 구절(개역한글 등)을 가사로 쓴 찬양을 새로 만들 때 성경 번역본의 저작권·허락 범위(개역한글·개역개정 차이, 대한성서공회 정책).
8. 위 결과를 바탕으로 "곡 1개를 넣기 전 확인 체크리스트"와 추천 운영안(곡 출처·기록 방식).

# 범위·조건
- 기준 시점: 2026-10 현재. 2023년 이후 자료 우선, 오래된 정보는 연도 표기
- 지역: 대한민국(한국어 예배) + 미국 기준(영어 예배) — 유튜브는 글로벌 플랫폼
- 제외: 일반 대중가요, 오프라인 예배당 공연권만의 문제
- 출처 우선순위: 저작권법 조문·한국저작권위원회·KOMCA·한국찬송가공회·대한성서공회·유튜브 공식 도움말·CCLI 공식 > 법률 전문가 해설 > 교계 언론 > 커뮤니티. 영어 원문 적극 검색
- 법률 자문이 아닌 정보 정리임을 전제로, 판단이 갈리는 지점은 "전문가 확인 필요"로 표시
