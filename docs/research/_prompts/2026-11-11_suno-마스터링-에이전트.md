# 역할
당신은 오디오 마스터링 엔지니어이자 음원 유통 실무 리서처, 그리고 파이썬 오디오 자동화 개발자입니다.

# 배경 (내가 만드는 것)
- 프로젝트: Suno(유료 플랜)로 만든 곡 중 좋은 곡만 골라 마스터링한 뒤 국내 음원 플랫폼(멜론 등)에 유통하려 함
- 환경: 개인 PC(Windows)에서 에이전트(파이썬 스크립트) 개발 → 상시 가동 Mac mini(Apple Silicon) 또는 리눅스 미니PC(Docker)에서 무인 실행
- 보유 자산: numpy/scipy로 직접 짠 EQ·컴프레서·게이트 + pyloudnorm 라우드니스 측정 코드(노래방 녹음 보정용). Windows에선 pedalboard가 segfault
- 이미 알고 있는 것: 국내 유통사별 AI 곡 수용 여부는 다르고(루트노트는 AI 100% 곡 국내 불가), Suno는 유료 플랜 다운로드만 상업 이용 가능, KOMCA AI 등록 보류. 이 부분은 다시 조사 불필요.

# 조사 목적
"Suno 원본 → 자동 선별 → 자동 마스터링 → 유통사 제출 규격 WAV" 파이프라인의 규격·도구·방법을 정하기 위함.

# 핵심 질문
1. 멜론·지니 등 국내 플랫폼과 국내/해외 유통사의 제출 음원 규격(포맷·비트뎁스·샘플레이트·True Peak·라우드니스 권장/요구)과 각 플랫폼 라우드니스 노멀라이즈(멜론 포함) 현황 — 현재 시점 기준
2. Suno 출력물(v4.5~v5, WAV/MP3, Suno Studio 스템)의 음질 특성·흔한 결함(고역 쉬머·금속성 아티팩트·노이즈·저역 탁함·클리핑·스테레오 문제)과 마스터링 전 처리법
3. 자동 마스터링 도구 비교: Matchering(레퍼런스 기반), Spotify pedalboard, ffmpeg loudnorm 2패스, 기타 오픈소스 vs LANDR·eMastered·BandLab·iZotope Ozone 등 상용 — 품질·비용·헤드리스(무인) 실행 가능성·Apple Silicon/리눅스 지원
4. Suno 곡 아티팩트 제거·복원용 도구(스템 분리 후 재믹스, AI 디노이즈/디에싱, 업샘플링 무의미 여부 등)
5. "좋은 곡" 자동 선별: 기술 지표(클리핑, True Peak, LRA, 스펙트럼, 아티팩트 검출)와 음악적 품질 평가(오픈소스 미학 점수 모델 등) 가능성, 사람 청취 단계 설계
6. 마스터링 후 품질 검증(A/B, 라우드니스 매칭 비교) 자동화 방법과 함정(과압축·인터샘플 피크·MP3/AAC 인코딩 후 클리핑)
