# 역할
당신은 교회음악(찬송학, hymnology)·작사작곡의 시니어 연구자이자, 예배용 회중 찬송을 직접 만드는 작곡 코치입니다.

# 배경 (내가 만드는 것)
- 프로젝트: 매일 유튜브로 내보내는 '말씀 묵상 예배'(한국어·영어)에 쓸 **자작 찬송가**를 AI 음악 도구(Suno)로 만들어 내 채널에 올리고, 예배의 찬송 시간에 '찬송가'로 사용하려 함. 같은 곡의 연주곡(가사 없는) 판도 만들어 기도회 배경으로 사용
- 현재 상태: 채널에는 CCM 풍 자작곡·연주곡이 섞여 있음. 목사님께 "찬송가는 만들어지는 원리(가사·선율 등)와 찬송가로 선정되는 기준이 있다"고 들었으나 구체적으로 모름
- 이미 아는 것: 저작권 만료 찬송과 저작권 문제는 별도로 정리함(이번 조사 제외). 성경 본문은 저작권이 끝난 개역한글을 씀

# 조사 목적
회중이 함께 부를 수 있는 '찬송가다운' 곡을 만들기 위한 작사·작곡 원리와, 찬송가집(한국 21세기 새찬송가, 영어권 주요 찬송가집)이 곡을 선정·편찬하는 기준을 정리해, 자작 찬송 제작 지침과 Suno 프롬프트 규칙으로 바꾼다.

# 핵심 질문
1. 찬송가(hymn)와 CCM·워십송·복음성가(gospel song)·시편가(psalm)의 차이를 가사 형식·선율·화성·용도 기준으로 비교(표). 예배 순서의 어느 자리(여는 찬송·응답·결단·파송·기도)에 어떤 성격의 곡이 맞는지.
2. 찬송가 가사의 원리: 운율(율격, meter — 8.7.8.7., C.M., L.M. 등)과 한국어 찬송의 음절 수 맞추기, 절(stanza) 구성과 신학적 흐름(찬양→고백→간구→헌신 등), 성경적 근거, 1인칭 단수/복수(우리), 피해야 할 표현. 한국어 번역 찬송에서 음절 맞추기 사례.
3. 찬송가 선율의 원리: 회중이 부르기 쉬운 음역(최저~최고음), 도약·순차 진행 비율, 프레이즈 길이, 반복 구조, 박자·템포, 조성 선택, 4성부 화성 전통. 숫자 기준이 있으면 제시.
4. 찬송가집이 곡을 선정·개편하는 기준: 한국찬송가공회(21세기 새찬송가 편찬) 공개 자료의 선정 원칙·심사 항목, 영어권(예: Hymnal 편찬 위원회, Hymn Society)의 기준, 교단별 신학 검토 기준.
5. 좋은 찬송가의 평가 기준·체크리스트(신학적 건전성, 문학성, 회중성, 음악성, 예배 적합성)와 실제 사용되는 평가표가 있으면 출처와 함께.
6. AI 음악 도구(Suno 등)로 찬송가풍 곡을 만들 때: 회중 찬송다운 편곡(피아노·오르간·합창 4성부), 프롬프트에 넣을 요소(율격·템포·음역·악기·보컬 스타일), 흔한 실패(가요풍 선율·과한 음역·불규칙 운율)와 피하는 법. 연주곡 판을 만들 때 주의점.
7. 이 기준을 적용한 '자작 찬송 제작 절차'(성경 본문 선택 → 가사 → 율격 점검 → 선율 → 편곡 → 회중 시범) 예시와 한국어 예시 1편(성경 구절 기반, 4절 이내).

# 범위·조건
- 기준 시점: 2026-10 현재. 고전 찬송학 문헌은 연도 표기, 최근 자료 우선
- 지역: 한국 개신교 + 영어권 개신교 찬송 전통
- 제외: 저작권 판단(별도 조사 완료), 특정 교단 교리 논쟁
- 출처 우선순위: 찬송학 교재·논문·찬송가 편찬 위원회 공식 자료·Hymn Society·한국찬송가공회 > 교회음악 전문가 해설 > 블로그·커뮤니티. 영어 원문 적극 검색

- 모든 사실 주장에 출처(제목·URL·발행일) 인라인 표기
- 각 결론에 확신도(높음/중간/낮음)와 이유
- 출처끼리 상충하면 양쪽 제시, 확인 불가한 것은 "확인 불가"로 명시
- 마지막에 "자작 찬송 1곡 만들 때 체크리스트"와 "Suno 프롬프트 규칙 예시", "추가로 조사할 질문 3개"
