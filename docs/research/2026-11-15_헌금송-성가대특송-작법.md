## 핵심 결론 5줄

1. **헌금 시간 음악은 짧다** — 출판사 봉헌곡은 대개 약 2분~2분 15초, 길면 3분 30초. 헌금 걷는 시간에 맞추는 게 원칙이고 늘이고 줄일 수 있는 곡이 쓸모 있다(확신도 중간 — 출판사·블로그 근거, 교단 공식 규정 없음).
2. **가사는 감사·청지기(맡은 것을 돌려드림)·자기 드림**이 흔한 주제(미가 6:6-8, 달란트 비유 등). 공연·과시가 되지 않게, 회중의 드림을 돕는 자리(확신도 중간).
3. **성가대 특송 구조**는 빨리 익힐 수 있게 반복이 많은 단순 형식 — 절+후렴, 반복되는 송영·후렴, "1절 독창(또는 여성/유니즌) → 2절부터 성가대 합류" 배치가 실무에서 쓰인다(확신도 중간).
4. **Suno는 부정 명령(no drums)을 잘 못 따른다** — 원하지 않는 단어를 빼고 반대를 묘사(organ, piano, rubato, sustained chords)하는 게 낫다는 커뮤니티 실무(확신도 낮음~중간, 비공식 가이드). 합창·화성·옥타브 상승은 곡이 쌓아 올린 뒤(후반)에만 넣으라고 권함.
5. **참고곡 I Surrender All**: Van DeVenter 작사·Weeden 작곡, 1896, **8.7.8.7 + 후렴**, Public Domain(Hymnary). 단 한국어 번역 가사(새찬송가 50장)는 공회 관리 대상 → 가사·선율 모두 새로 쓰고 '형식·정서'만 빌린다(기존 저작권 조사와 일치).

## 1. 봉헌 시간 음악 관례

| 항목 | 내용 | 출처 |
|---|---|---|
| 길이 | 찬송 기반 봉헌곡 약 2분, 청지기 앤섬 약 2:15, 긴 것 약 3.5분 | 출판사 목록(Cokesbury, Sheet Music Plus, CPH 'Offertory Mosaics') |
| 시점 | 헌금 걷는 동안 또는 그 앞뒤 | CPH 블로그 |
| 목적 | 드림을 돕는 것, 연주자 쇼케이스 아님 | Ashley Danyew 'Music for Stewardship' |
| 본문 | 미가 6:6-8, 달란트 비유 등 청지기 주제 | 같은 글 |

- 피할 표현(기존 작법 조사 + 신학): "드리면 갑절로 받는다" 류 대가성·기복, 액수·비교.
- 권할 이미지: 과부의 두 렙돈(막 12:42), 오병이어 소년의 도시락(요 6:9), 마리아의 향유(요 12:3), 산 제물(롬 12:1), 모든 것이 주께로부터(대상 29:14), 즐겨 내는 자(고후 9:7), 첫 열매(잠 3:9).

## 2. 성가대 특송 구조 (헌금 시간 규모)

- Reformed Worship(Stam): 가사가 먼저, "이해할 수 있고 성경 강조점과 맞아야", 성가대 찬양이 오락이 되지 않게. ✅ 원문 확인
- 실무 배치(출판사 해설): 독창 절 → 성가대 합류, 2절부터 성가대 진입, 반복으로 익숙해지는 구조.
- 이 프로젝트 권장(공식 규정 아님): 3~4분, `[Intro] → 1절(유니즌 또는 여성) → 후렴(SATB) → 2절(SATB) → 후렴 → [Bridge] 짧게 → 마지막 후렴(조옮김 1회 허용) → Amen 종지`.

## 3. Suno 합창 프롬프트

- jackrighteous 워십 태그 가이드(V5): hymn-like 레인 예시 "hymn-like worship, clear congregational lead, piano or organ, steady tempo", "simple harmony… minimal production effects". 합창·옥타브 상승·드럼은 곡이 쌓아 올렸을 때만. 팝처럼 들리면 무관한 프로덕션 단어 제거. ✅ 원문 확인
- 커뮤니티 가이드: 부정 프롬프트 칸이 없음 → "no drums"보다 단어 자체를 빼고 반대 묘사. 기존 찬송 앨범에서 쓴 `no …` 나열은 효과가 보장되지 않음(그래도 해 없음 → 짧게 유지).
- 합창 레이어링은 Suno가 약하다는 주장(업체 글, 신뢰 낮음) → 가사 창에 `[Choir]`, `[SATB harmony]`, `[Women]`, `[Men]` 섹션 태그로 역할을 나눠 주는 편이 낫다.

## 바로 적용할 체크리스트

- [ ] 찬송가풍: 8.7.8.7 + 후렴, 3절, 2:30~3:30, 76~80BPM 4/4, 오르간+피아노
- [ ] 성가대 특송풍: 3~4분, 유니즌→SATB 확장, 마지막 후렴 한 번만 고조, Amen 종지, 드럼 단어 없음
- [ ] 가사·선율 100% 창작, 50장 문구("내게 있는 모든 것을", "주께 드리네" 반복 구조) 그대로 쓰지 않기
- [ ] hymn_check 로 절 율격 검사
