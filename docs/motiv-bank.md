# 동기부여 원고 은행 (nexis-motiv '하루 한 줄, 동기부여')

원고는 이 레포 `data/motiv/*.jsonl` 에 쌓는다(데스크탑 Claude 세션에서 무과금 작성). 한 줄 = 원고 한 편.
맥미니 `scripts/worship/motiv.py --bank` 가 아직 안 만든 원고를 차례로 영상으로 만들어 `~/Work/outbox/motiv/<id>/` 에 넣고,
`archive-outbox.sh`(10분 주기)가 미니PC `/mnt/external/macmini/<이관 묶음>/motiv/` 로 옮긴다. **업로드는 아직 없다.**

## 한 편의 형식

```json
{"id": "m0001", "theme": "월요일 아침", "title": "…", "line": "…", "body": "…", "close": "…"}
```

| 칸 | 규칙 |
|---|---|
| id | `m` + 네 자리, 은행 전체에서 하나뿐. 만든 기록(맥미니 `~/Work/nexis-motiv/output/done.txt`)도 이 id 로 남는다 |
| title | 유튜브 제목, 25자 이내, 듣는 사람의 상황이 보이게 |
| line | 하루 한 줄, 12~24자, 화면에 크게 뜬다 |
| body | 5~7문장, 한 문장 12~32자. 구체적인 장면 하나(시간·장소·행동)로 시작해 마음의 전환으로 |
| close | 오늘 해 볼 아주 작은 행동 하나, 30자 이내 |

공통: 숫자는 한글로, 영어·괄호·따옴표·이모지 금지, 모든 문장은 마침표·물음표로 끝. 명언·유명인 인용·통계 금지(출처 확인 불가).
상투어 금지 목록과 중복 검사는 `scripts/worship/motiv_check.py` 가 본다 — 은행에 넣기 전 반드시 통과.

```bash
python scripts/worship/motiv_check.py data/motiv/*.jsonl
```

## 주제 지도 (같은 말 되풀이 막기)

한 묶음(25편 안팎)은 아래 칸을 고루 돈다. 같은 칸이 연달아 나오지 않게.

| 칸 | 상황 예 |
|---|---|
| 시작 | 월요일 아침, 새해·새 달, 첫 출근, 미뤄 둔 일 |
| 지침 | 퇴근길, 번아웃, 잠 못 드는 밤, 주말이 끝날 때 |
| 실패 뒤 | 시험·면접 낙방, 실수한 날, 거절당한 날 |
| 비교 | 남의 소식, 늦었다는 느낌, 동기의 승진 |
| 관계 | 서운한 말, 혼자라는 느낌, 사과하기 |
| 습관 | 운동, 독서, 일찍 일어나기, 휴대폰 |
| 공부·시험 | 시험 전날, 성적표, 공부가 안 될 때 |
| 돈·일 | 월급날, 일이 안 풀릴 때, 이직 고민 |
| 몸·마음 | 아픈 날, 불안, 화가 날 때 |
| 작은 기쁨 | 날씨, 계절, 소소한 성취 |

## 배경 (10-25 사용자 확정)

장면 그림과 미소녀풍 그림을 **번갈아** 쓴다. 맥미니 `~/Work/nexis-motiv/bg/<주제키>_<scene|girl>.<png|mp4>` 에서
원고 주제로 고르고, 편 번호 홀수 = 장면 먼저, 짝수 = 미소녀풍 먼저. 같은 이름의 mp4(반복 영상)가 있으면 그것을 쓴다.

| 주제 | 키 | | 주제 | 키 |
|---|---|---|---|---|
| 시작 | start | | 습관 | habit |
| 지침 | tired | | 공부와 시험 | study |
| 실패 뒤 | fail | | 돈과 일 | work |
| 비교 | compare | | 몸과 마음 | mind |
| 관계 | relation | | 작은 기쁨 | joy |

- 그림 20장(Higgsfield GPT Image 2.5, 장당 0.25크레딧), 반복 영상은 **시작 주제 2개만**(Kling 표준·무음 5초 7.5크레딧, 앞뒤로 이어 붙여 10초 무한 반복). 더 늘리지 않는다.
- 미소녀풍 = 25세 안팎 성인 여성, 단정한 일상복, 선정성 없음. 원본은 데스크탑 `D:\YH\output\motiv-bg`.
- 그림은 천천히 확대(방향은 편마다 다르게), 글 뒤엔 옅은 그늘·그림자. `bg/` 가 없으면 예전 단색 바탕.
- 비교본: `python motiv.py --bank bank --compare m0001 --bgs none,start_scene.png,start_girl.mp4`

## 미니PC 외장하드 정리

맥미니가 보낸 영상은 이관 폴더(`/mnt/external/macmini/<시각>/motiv/`)에 흩어져 들어온다.
미니PC 에서 `python3 ~/bin/motiv_collect.py` 를 돌리면 `/mnt/external/nexis-motiv/` 의
`영상/`(편마다 최신본)·`원고/`·`이전본/`·`목록.md`·`목록.csv` 로 모은다. 자동 실행은 아직 없음(미니PC 설정 변경은 승인 후).

## 맥미니 실행

```bash
# 은행의 안 만든 원고를 아침 7시까지(또는 다 할 때까지) 차례로
python motiv.py --bank ~/Work/nexis-motiv/bank --until 07:00
```

- 예배 목소리 작업(build_worship·simbang)이 돌고 있으면 끝날 때까지 기다렸다가 이어 간다(예배가 우선).
- 한 편 약 3분(Apple GPU, 4GB 안팎). 실패는 건너뛰고 기록, 연달아 3번 실패하면 멈춘다.
- 다 만든 편은 작업 파일(frames·_chunks·wav)을 지우고 mp4·script.json 만 남긴다.
